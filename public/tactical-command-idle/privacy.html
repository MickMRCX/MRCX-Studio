Privacy Policy

Tactical Command Idle — Draft reviewed October 12, 2026; not yet effective

Pending release verification

This draft is not ready for store submission. The updated package manifest does not declare an advertising SDK. Native dependencies and the final build still need verification to confirm the planned advertising-free release. Services, diagnostics, purchases, retention and audience details marked below require confirmation.

01Game and Developer

MRCX Studio develops Tactical Command Idle, formerly Project Breach, a tactical idle management and strategy game for Android and iOS.

This draft is based on the updated package manifest supplied by the developer and the previously reviewed game implementation. The planned release has no advertising. The final build must be checked before this policy becomes effective.

02Data and Purposes

The reviewed implementation integrates optional Unity Analytics to understand usage, improve game balance and investigate technical failures. Collection is gated by the analytics consent choice.

Unity Analytics may process IP address, installation-specific and analytics user identifiers, and IDFV on supported Apple devices, alongside session, device, operating system and app version information. The exact automatic payload in the release build remains to be verified.

Custom events cover building construction and upgrades, agent recruitment and promotion, mission starts and outcomes, difficulty, duration, team size, success probability and in-game rewards. Technical events report mission resolution and save restoration failures using categories. Agent and building identifiers refer to game content.

03Third-Party Services

The updated manifest declares Unity Analytics 6.3.0, Unity IAP 5.4.3 and Unity Mobile Notifications 2.4.3. Unity Gaming Services Core initialization was identified in the previously reviewed implementation; resolved transitive dependencies must be checked against the updated package lock file. Unity Authentication and Cloud Save are not declared in the supplied manifest, and no corresponding integration was found in the previously reviewed gameplay scripts; final build behavior still needs verification.

Unity Mobile Notifications 2.4.3 is integrated for local mission and building notifications. Notification preferences are saved on the device; operating system permission and game settings control notifications.

See the Unity Game Player and App User Privacy Policy, Apple Privacy Policy and Google Privacy Policy.

04In-App Purchases

Unity IAP integration exists for store purchases. The reviewed code processes product and transaction identifiers, validates purchases through a receipt-validator interface and stores a local transaction ledger to prevent duplicate credit.

To confirm: whether purchases will be enabled at launch, the Apple and Google store configuration, the production receipt-validation implementation, and any backend receipt or transaction processing. A concrete production validator was not found in the reviewed scripts. Payment-data access and provider retention must be confirmed before release.

05Save Data and Storage

The reviewed save system stores game progression in local files under the application data directory, including base, personnel, missions, economy and purchase-credit records. Settings and notification preferences are stored locally; Unity persists analytics consent separately from game saves.

To confirm: operating system backup behavior, deletion/reset behavior, and any remote storage or purchase-validation backend added before release. Local saves do not establish that no data is transmitted by other services.

06Retention

No project-specific remote retention configuration was verified. Local data persists until removed by the game, user or operating system, subject to platform backup behavior.

To confirm: configured Unity Analytics retention, support correspondence retention, any purchase-validation retention, and deletion procedures. No fixed retention period is asserted in this draft.

07Service Providers and Sharing

When analytics is allowed, analytics and progression events are sent to Unity for analysis and diagnostics. If store purchases are enabled, purchase information is processed through the relevant platform and configured purchase services.

To confirm: the final recipient list, any validation backend, processing locations and contractual arrangements. This draft does not assert unverified restrictions on sharing.

08Privacy Choices and Requests

The reviewed code presents an initial analytics choice and allows that choice to be changed in Settings under Usage Analytics. Refusing analytics does not block gameplay; custom analytics events require granted consent. Withdrawal is not a request to delete previously collected data.

Contact contact@mrcx-studio.com about access, correction, deletion or other privacy requests. Available rights depend on applicable law.

To confirm: the request-handling process, identification of analytics records, provider deletion workflow and final on-device consent behavior.

09Children's Privacy

To confirm before publication: the intended audience, age rating, whether children are included, and any necessary age or parental consent measures. This draft makes no unverified claim that the game is not directed to children.

10Security and Diagnostics

In the previously reviewed project settings, Cloud Diagnostics reporting and the crash-report API were disabled, while engine diagnostics was enabled. The updated package manifest alone does not establish the current diagnostics configuration. Consent-gated custom technical events are implemented through Analytics.

To confirm: engine diagnostic transmissions and controls, release crash-reporting behavior, security measures and any server-side services. No guarantee of complete security is made.

11Changes to This Policy

This draft must be updated after release-build verification, with an effective date when approved for publication. Later changes to features, providers or data processing should be reflected here.

The game-specific policy URL is https://mrcx-studio.com/tactical-command-idle/privacy.html.
